# 聚合物晶体计算方法与验收口径

本项目面向聚合物晶体结构重建与分层精修。本说明以 2026-10-29 固化的 PE 技术路线 v1.0 为已验证实例，说明计算阶段和验收方法；下列材料参数及数值结果属于 PE，推广到其他聚合物时需重新确定并验证。原始协议、参数锁、结构哈希和终态验收记录决定历史计算事实。本仓库 v0.1 是源码与精选证据准备快照，不能替代各阶段原始输入。

完整路线：[技术路线.md](../snapshot/reports/PE技术路线_v1_0_20261029/技术路线.md)；机器可读定义：[route_lock.json](../snapshot/reports/PE技术路线_v1_0_20261029/route_lock.json)。

## 1. 模型与候选生成

| 项目 | PE 实例 |
| --- | --- |
| 组成 | C4H8，12 atoms，4 CH2，2 条无限全反式链 |
| 链轴与晶胞 | 链沿 c；a/b/c = 7.432/4.929/2.545 Å，角度均为 90° |
| 对称性 | Pnam，No.62，Hall 297，8 个操作 |
| 初始化学几何 | C—C = 1.54 Å；C—H = 1.09 Å |
| 枚举 | 36 个 setting 角 × 4 个链轴位置 × 2 个相位 = 288 |
| setting 角 | 链平面在 ab 平面投影相对 +a 的角度；0–175°，步长 5° |

晶胞和空间群属于文献先验。候选生成不读取文献精修原子坐标或实验 setting 角；两碳纯平移短周期限定当前全反式模型，不代表长周期缺陷构象被排除。

非键接触阈值为 Bondi 半径和乘 0.85：C···C = 2.89 Å、C···H = 2.465 Å、H···H = 2.04 Å。周期化学图距离为 1 或 2 条键的近邻不计入此检查，另检查链间 C···C ≥ 3.4 Å。

288 个候选中 40 个因接触检查被排除，248 个通过；232 个是等价表示，去重后保留 16 个独特初态。80/85/90°独立角度类没有开展量化优化。0–75°是当前接触阈值形成的存活初态域，不能表述为所有不等价取向的普适上限。

## 2. 周期 GFN2 预优化

GFN2-xTB 使用 tblite 0.7.0，经 ASE 调用。周期采样采用 Γ 重复超胞，复制数不能写成显式 k 点网格。

| 阶段 | 设置与验收 |
| --- | --- |
| 粗优化 | 2×2×6，accuracy 0.01，原始 Fmax 目标 0.03 eV/Å |
| 精优化 | 2×3×8，accuracy 0.01，固定胞/Pnam 投影，原始 Fmax < 0.01 eV/Å |
| 冷启动 | accuracy 0.001，独立终态电子复核 |
| 代表加密 | 3×4×10 同几何；每 CH2 能差 < 1 meV，最大原子力矢量差 < 0.005 eV/Å，加密自身 Fmax < 0.01 eV/Å |
| 电子占据 | 优化 300 K；标定生产 0 K；均不代表有限温度原子动力学 |
| 标定生产 | 冻结几何，2×3×8，accuracy 0.001，max_iterations 1000，中性闭壳层 |

原胞能量按复制数归一，力按等价副本平均，同时保留原始力、投影力和副本偏差。cand_0025、cand_0065 曾追加至 0.003 eV/Å；新几何需要自己的终态验收。

16 个初态完成预优化。0°驻点沿保持目标对称性的 ±1°扰动均降能，因此单独排除；该检查不替代完整 Hessian 或声子。15 个保留终态形成 g1/cand_0025、g2/cand_0113、g3/cand_0041、g4/cand_0081 四个代表。

## 4. 同几何标定

21 套冻结几何包括 16 初态、4 代表终态、1 个方向不稳定驻点对照。PBE-D3(BJ) 计算 21 点，另外两种方法各 4 点，总计 29 个生产配对。

以 final_group_001 的 GFN2 冻结几何为共同参考身份 R0，各方法分别使用自己的参考能量：

```text
ΔE_i(M) = 1000 × [E_i(M) − E_R0(M)] / 4     meV/CH2
e_i = ΔE_i(DFT) − ΔE_i(GFN2)
b = mean(e_i)
σ = std(e_i, ddof=1)
```

主统计仅针对 16 初态：b = 4.6383338759、σ = 1.9206975072、3σ = 5.7620925215 meV/CH2。适用域为该 PE C4H8 固定胞、全反式构造、0–75°每 5°初态网格。

这是同批样本的经验描述，不承诺 99.73% 覆盖，不外推到变胞、缺陷、优化终态或其他聚合物。均值校正不改变候选间排序；R0 按定义保持零点。本轮没有设置低能窗口 W，能量自动淘汰数为 0，四代表全部进入 DFT。

## 5. 固定胞精修、合并与变胞

固定胞采用 FixSymmetry + LBFGS，maxstep 0.05 Å、maxsteps 200；先以原始 Fmax ≤ 0.002 eV/Å 优化，再加严至 ≤ 0.0002 eV/Å。验收使用未投影原始力；固定胞残余应力只记录，不要求零压。

终态合并在允许的周期映射、原点平移、正交反射和同元素置换中，要求**同一映射**同时满足 RMS ≤ 0.02 Å、最大原子位移 ≤ 0.05 Å，且同方法能差 ≤ 1 meV/CH2。严格固定胞使用全部 6 对比较与完整链接分组。GFN2 历史分组按原实现保留，不追认成同一算法。

四代表严格精修全通过，全部 6 对满足合并条件；最大两两 RMS = 0.000324747 Å。g1/g2 最终接受 attempt_02，g3/g4 接受 attempt_01。g4 是记录代表；组内微小能差不支持独立晶型排序。

| 结构身份 | 关键结果 |
| --- | --- |
| 严格固定胞 g4 | a/b/c = 7.432/4.929/2.545 Å；原始 Fmax = 0.000171616 eV/Å；setting 角约 45.74867° |
| 新变胞 g4 | a/b/c = 7.129506/4.908356/2.555579 Å；冷启动原始 Fmax = 0.000620992 eV/Å；max 六应力 = 0.011392944 kbar |

新变胞由严格固定胞 g4 起步，采用 FixSymmetry + FrechetCellFilter + LBFGS，零外压、mask=[1,1,1,0,0,0]，释放内部原子与独立 a/b/c，角度保持 90°。其门槛是 Fmax ≤ 0.002 eV/Å 与 max 六应力 ≤ 0.05 kbar，不能写为固定胞的 0.0002 eV/Å。

独立冷启动不继承电子密度或波函数。终态再分别加严 k=5×10×15、gpts=128×80×48、Ecut=2000 eV；截断能比较使用同为 128×80×48 的 grid_only 点作基线。三项通过属于冻结末态单点复核，不是加严设置下重新优化。

## 6. 单位、实验对照与解释

本胞含 12 atoms、4 CH2；meV/atom 与 meV/CH2 必须区分。能差从 eV/cell 到 meV/CH2 乘 250。应力为 ASE 拉伸正号，Voigt 次序 xx、yy、zz、yz、xz、xy。

固定胞 g4 与 Tashiro 的 12 原子坐标比较 RMS = 0.026947 Å，最大三维偏差 = 0.039811 Å。文献 H 坐标存在几何约束，不能视为无误差真值；Tashiro 测量温度未核实，不写“室温”。

4.5 K 参考胞为 7.128/4.852/2.553 Å；新变胞逐轴相对差约 +0.0211%、+1.1615%、+0.1010%。静态零压结果不包含零点振动或热膨胀。

XRD 对照为 59 行 hkl 索引、45 个不同印刷 d 值、Mo Kα 波长 0.71073 Å。固定胞和变胞平均绝对相对 d 偏差分别为 0.287906% 和 1.647915%，应保留变胞在该峰位对照中没有改善的结果。固定胞峰位吻合受实验晶胞先验影响，不能独立验证原子坐标。缺少同一样品实测连续强度谱，不报告 Rwp 或整谱匹配率。
