## 主要意见及我们的理解

1. **重新审视 GFN2 预优化的成功标准。** Pro 认为，低成本步骤不必自行完成目标氢键片层，更关键的是保持合法结构和有价值的起点多样性，让 DFT 能够纠正。单候选未成网不能判定整个路线失败。本地判断：该区分值得采纳为后续评价原则，但“保留多样性”仍需起点—终态身份及直接 DFT/经 GFN2 的匹配比较，当前并未验证。
2. **周期可用性检查与早期独立 DFT 对照并行。** 建议在冻结收紧终态上，分别检查 1×2×1→1×4×1 与 1×2×1→2×2×1，设计算预算上限；将少量独立 DFT 冻结力检查提前，包含预先固定的破缺扰动，而不是无上限追逐大复制胞。若 GFN2 自身表示未稳，跨方法分歧仍不能直接归因于其物理模型。上述复制数组只是提案，并未得到本项目收敛验收。
3. **分开检验注册与约束，不混改起点。** 明确列出四操作、八操作、原子映射和允许空间；用额外允许方向及正负成对扰动检查禁向。Pro 强调四个独立方向分别升能不证明四维空间正定，混合二阶项尚未检验。P1诊断轨迹也不是已完成的 D1/D14 无序分支。
4. **PE 保持现有有限主张即可。** 如实保留 b 轴偏差和变胞后索引峰位误差增大的结果；声子、跨泛函几何、核自由能应对应所要扩大的主张，不必全部变成当前路线交付的前提。不同实验条件的峰表与低温晶胞仍需分别解释。

## 不能直接照搬的细节

- Pro 的表格将“扰动后明确降能”写作方向不稳定证据。实际执行时须区分残余一阶梯度、有限位移进入别的区域及负曲率；不能只凭一个有限扰动点降能声称已证明局部动力学不稳定。应配对正负位移，核查数值噪声、步长敏感性及对称二阶差分，结论限于所测方向。
- 投影差 P4−P8 的解释依赖同一笛卡尔度量、固定原子映射、正交投影及嵌套子空间；应先验证这些条件、群闭合与投影秩，不能只将符号公式直接变成代码。
- Pro 提出分层随机选相位、几何不合格时按预先规则补位；原协议为固定索引 0/6/12/18、不按氢键替换。新的抽样/补位规则若采用，需要另版本登记，保留原失败记录。不能追溯改变已有候选的选择依据，也不能在看过氢键结果后称为完全盲选。
- Pro 给出的 0.005 eV/Å 是粗预优化的示例差值预算，不是已批准的生产验收标准。要判断 0.005 eV/Å 级驻点，数值误差应明显更小。尚未运行的新相位、扰动与更密复制胞不应继承旧点的收敛标签。
