**1. 这次先固定的边界**

主体是普通 PA6。首轮不单独进行氘代候选搜索、静态优化或同位素声子计算；与论文中子数据比较时，只将亚甲基 H 映射为 D，NH 保留 H。有限温度及同位素自由能在问题需要时另行扩展。

原文 Table 1/SI 原子坐标、由其反推的模板或几何均不进入候选、优化起点及阈值调参。生成器只读取白名单字段和独立模板；不读取 PDF 或全文提取文件。晶胞、轴序、化学连接、群操作和声明的堆垛假设可作为先验。用于比较的衍射数据与生成输入分开管理。

**2. 三条独立分支**

| 分支 | 候选生成 | 必须单独验收的内容 |
| --- | --- | --- |
| O 有序 P112₁/n | 采样独立化学链的位置、取向、相位及构象，再按声明操作展开 | 每个周期候选的化学连接和逐原子对称性 |
| D1 统计无序 P1 | 独立采样满占位层序、相对错移和局部域，不预设高对称平均关系 | 真实相对无序、微态合法性、统计相关性及采样 |
| D14 统计无序 P112₁/n | 按独立的对称轨道与概率约束生成满占位微态集合 | 微态合法性，生成及精修后的平均计量、概率关系和平均对称性 |

D14 的每个微态不必具有 P112₁/n；平均对称性不能成为抹除局部无序的原子约束。D1 若出现更高对称性，记录恢复结果并保留来源。三路共享独立化学模板和数值工具，但生成协议、候选库、组号、统计权重及覆盖记录独立；跨路只建立结果关联。

**3. 如何开始**

第一项工作是冻结输入与独立化学模板的构造方法。先根据 [-NH-C(=O)-(CH₂)₅-]ₙ 的共价连接定义原子角色，建立内部坐标和跨胞连接。键长、键角等来自独立通用化学参数或独立片段计算，记录来源；不能为凑到 c 轴周期而任意缩放所有键长。链的周期闭合通过内部自由度和约束求解检查，失败样本保留失败原因。

三个生成器从这个共享的独立化学基础各自采样。初期优先生成能检验规则的少量几何样本，随后再扩大覆盖。先不按低成本能量淘汰候选。

首个可验收交付是：**三套候选库、每个结构的化学/片层/堆垛身份、几何与识别测试结果。** 它通过后才进入 PA6 数值先导。

**5. 首批几何和量化先导怎样选**

| 分支 | 几何对照至少覆盖什么 |
| --- | --- |
| O | 不同链位置/取向/轴向相位；保留至少两种内部构象或酰胺几何起点 |
| D1 | 注册比例相近但排列相关性不同的层序；另含 c 向错移和边界对照 |
| D14 | 相同平均对称假设下，不同局部相关性与位移的集合；检验对称轨道及权重关系 |

在三路几何验收后，首批量化先导暂按每分支最多两个独立代表估算资源，总计约六个。此数是可调整的试跑规模，不是完整候选覆盖或无序采样数量；不能为满足数量上限截断 D14 的必要轨道或误把等价轨道成员计作独立样本。数值先导可只计算代表，集合衍射结论必须等到所需微态与采样检查完整后给出。

主线候选为 PBE-D3(BJ)+ATM。先对各分支代表确定数值和资源需求，再对最有竞争性的结构用 r²SCAN-D4 复核；涉及氢键几何的结论需要第二方法的代表优化。GFN2 计划用于本机 O 分支预优化；不负责首轮自动归并或能量剪枝。氢键形成及网络变化属于后续结构分析，不决定初始候选的保留、排序或代表选择。当前仍暂停预优化。

起步原始 Fmax 可参考 0.002 eV/Å，但所有生产参数保持未验证状态，直至 PA6 先导通过。相对能精度、局部几何稳定性、应力和冷启动分别验收。固定胞结果不以零应力为要求。

**6. 结构身份和验证**

每个结构保存不可覆盖的分支、生成器版本、来源哈希、原子角色、周期共价图、氢键几何、层序及边界位置。无序模型额外保存集合、微态、权重、相关性；初始假设、终态微态对称性和集合平均对称性分开。

识别器需要认回原子重编号、整胞平移、合法换胞及重复超胞；需要检出已确认非等价的片层滑移、c 向错位和局部连接变化。使用同一整体映射，不能逐片层独立对齐来消除层错。显式邻胞枚举用于独立检查非正交距离；扩大超胞后，局部缺陷仍须检出。

全胞 RMS、局部最大偏差和各界面位移分别报告。几何相似、能量近简并、优化进入同一终态和实验不可区分是不同结论。阈值经过敏感性检查后再锁定。

**7. 实验数据如何使用**

生成和 DFT 筛选阶段冻结后，将实验强度用于结构比较。若使用强度优化集合参数，该部分属于拟合，不能再作为独立验证。数据足够时预先登记内部留出峰组；重叠 hkl 必须整组划分，尺度从拟合部分确定。逐层缩放的文献 R 复现和留出残差分开记录。

论文和模型已经被阅读，因此不能称对分析者完全盲。现有数据不足以留出时，如实报告拟合及不可辨识范围。h10 与 d10 制样不同，联合比较需要保留各自样品身份和必要参数。
