# PA6 phase0 粗优化终态的几何诊断

本文件仅基于独立生成的候选、既有优化轨迹及几何对照；未读文献原子坐标，未计算新能量，未按氢键淘汰或选择计算代表。原子编号从 0 开始。

**主要发现：没有发现原子映射、周期图像、角度定义或截断错误。最近 N···O 已靠近，但 N–H···O 方向仍较弯；保持相同 No.14 和额外 b/2 平移的其他相位可以具有完整几何氢键片层，说明当前 phase0 的局部结果不能代表整个有序分支。**

## 链位置与相位

链轴仍沿 c。两组原链层的骨架质心保持在法向 y≈0 和 y≈3.5071 Å，原有横向轴位置基本未移动；同层链轴间距为4.715 Å，层间法向距离约3.507 Å。骨架从初始平面向层法向弯曲，终态每条链的骨架法向范围约质心±0.2441 Å。

链0/1的质心 c 向位移约 +0.06127 Å，链2/3约 −0.06127 Å；骨架均值相应为 ±0.08002 Å。局部连续 N/C/O 酰胺中心的平均 c 向位移仅约 ±0.02200 Å，反向链相对改变约0.044 Å。这些量是结构变化的不同描述，不能把有限链段质心的绝对 c 坐标当成唯一注册相位。JSON 同时保存了固定分支切口的链质心、逐酰胺局部相位及 N 原子锚点。
