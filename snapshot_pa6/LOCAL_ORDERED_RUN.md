1. 从化学连接与独立通用化学参数构造周期链；记录参数来源、跨胞共价边、原子角色及闭合残差。
2. 在生成前冻结本批采样范围，再按四个声明的对称操作构造有序候选。记录所有生成、过滤与失败数量；不做能量剪枝。
3. 独立验收计量、共价化学几何、周期链、非正交最小距离、非键重叠和逐原子对称操作；物理筛查不计算氢键，不使用其距离、角度、覆盖率或片层连通性淘汰、排序或抽取代表。验收身份保持与构型相连。
4. 核查本机 GFN2 环境和资源，先运行一个候选的固定胞预优化，再按实测安排其他候选。
5. 保存所有候选预优化前后的原始力、氢键、链构象与堆垛变化。GFN2 能量不用于自动淘汰或合并；有序候选覆盖、周期采样和后续 DFT 精度分别验收。

## 本机资源原则

使用现有 WSL Ubuntu 24.04 的 CPU 环境，不修改 PE 历史计算。现场可见 WSL 总内存约 15.2 GiB；GFN2 首轮计划单任务、少量 CPU 线程，给桌面及操作系统留余量。具体并发按真实峰值和耗时安排。GPAW 仅可准备云端运行接口，不在本机启动 DFT。

不改变 WSL 全局内存配置、不终止其他工作；新依赖放在 PA6 专用位置。每次计算使用独立输出目录，保存输入、代码和 PAW 哈希、日志、重启数据以及真实收敛状态。

## 验收与结论边界

固定胞首先使用文献白名单的 100 K 晶胞作为先验。对称约束用于定义本轮有序分支；投影力和原始力分开，后续约束释放与变胞检查另记。GFN2 预优化不等同 DFT 精修；电子展宽温度不等于核温度，Gamma 基础胞的周期采样未验证时必须明确标记。初始结构不要求已有氢键或片层网络；这些性质留作后续独立分析。
