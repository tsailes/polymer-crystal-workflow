# 尼龙6氢键片层与堆垛结构联合精修方案

2026 年 10 月 29 日，方案 v0.3。研究范围为普通尼龙 6 α 型的静态结构。候选不使用原文原子坐标，三类模型分别生成、计算和分组；首轮氘代仅用于中子衍射权重映射，不单独搜索、静态优化或计算同位素振动。具体数值参数须经 PA6 先导验证后锁定，当前未启动量化计算。

**核心问题：局部氢键片层在不同堆垛环境中如何调整，这些局部结构能否共同解释 X 射线和中子衍射？**

片层内氢键结构是重点；片层错移、短程堆垛和小域边界同样属于本次必须完成的结构精修。采用完整周期晶体和满占位超胞，计算堆垛时继续允许片层内部原子弛豫。相较于此前扩展评估，本方案把堆垛超胞精修纳入首轮模型库和正式交付。

PE 路线的迁移审查、文献输入字段、对称性判定和结构识别门槛见配套[方法与识别规范](E:/PE_DFT/reports/PA6计算实验设计_20261029/PE路线迁移与结构识别规范.md)。首批保留各类起点的直接 DFT 通道；GFN2 只在匹配支路中检验是否保留目标结构，暂不据其归组压缩 DFT 起点。

PE 是该思路的最小可行性实例；PA6 扩展其候选生成、结构识别与验收能力。三条独立分支及 h10/d10 处理详见[三分支候选生成与氘代处理](E:/PE_DFT/reports/PA6计算实验设计_20261029/三分支候选生成与氘代处理.md)。

**1. 研究目标及可检验结果**

| 目标 | 需要回答的问题 | 对应结果 |
| --- | --- | --- |
| 氢键片层精修 | 酰胺 H、供受体相对位置、骨架扭转与片层起伏如何变化？不同堆垛是否保留相同的局部氢键网络？ | 每条不等价氢键和骨架几何，按片层内部及边界附近分组 |
| 堆垛与边界精修 | a 向滑移和 c 向错位有哪些可保持的局部结构？哪些在释放约束后回滑或重排？ | 受约束能量面、自由优化终态、精修后的层错和小域边界 |
| 结构与衍射对应 | 哪些局部结构组合能改善有序模型的不合理强峰？现有数据能区分哪些堆垛分布？ | WAXD/WAND 共同检验、少量统计参数的可接受范围及不可分辨项 |

既允许得到多个近简并结构，也允许发现某些候选会回到同一结构。不同初始构型的合并、降对称或层错消失都属于结果，不能预设全部终态必须归为一组。

**2. 三类独立候选库**

原文 Table 1 和 SI 的原子坐标不进入候选生成、链模板、优化起点或阈值调参；也不通过复制后扰动、平均或拟合的方式间接使用。先由 C6H11NO 化学连接、独立来源的内部几何或独立片段优化生成周期链，再按各分支规则构造晶体。化学几何的来源与计算参数另行登记。

文献可提供组成、晶胞、链轴、对称操作及堆垛假设。使用作者轴序：c 为链轴，单斜角为 γ。100 K 胞可作共同固定胞条件：a=9.43、b=7.62、c=17.46 Å，γ=67°。8 个重复单元对应 152 原子仅为组成规模基准，独立生成后仍须核验周期连接。[1，第 4–7 页]

| 分支 | 专用候选生成规则 | 对称性与计算对象 |
| --- | --- | --- |
| O 有序 P112₁/n | 从独立化学链构造不对称单元，枚举链摆放、方向、轴向相位及内部构象，按明确操作生成有序周期胞 | 候选满足该有序结构假设；在分支内做约束优化及释放对称性的复核 |
| D1 统计无序 P1 | 独立采样满占位片层排列、局部错移、c 向位移及相关长度假设，不施加非平凡的集合平均对称性 | DFT 分别计算真实微态；统计集合不预设 P112₁/n，不是从 O 末态随意加噪声 |
| D14 统计无序 P112₁/n | 用独立的对称轨道、相关层序及配权规则生成无序集合，要求集合概率在指定操作下不变 | 平均结构满足 P112₁/n；每个满占位微态可以降对称，不能统一给所有微态加 FixSymmetry |

三分支采用不同生成协议、候选编号、筛选记录和组号，分别提交计算、验收和分组。允许共享独立的化学模板、周期几何和电子结构求解模块；不能共享一个候选库仅修改空间群标签。跨分支终态如有相似性，只建立关联，保留各自来源和结果。

same-height/zigzag、up–up/up–down 是具体高度和注册对照，不替代上述三类分支。首批数量由各分支覆盖的独立自由度确定，不再把“三个有序对照＋两个层序”视作三类统计模型已经覆盖。短序列可用于无序分支的局部环境先导，但单个周期序列不是完整随机无序集合。

片层内上/下链交替，与跨片层的 up–up/up–down 关系分开记录；same-height/zigzag 是沿 c 的高度变量，也应单独记录。不能把这两类变量合并成同一个结构开关。[1，第 6–8 页]

SI 的占位讨论仅用于理解统计假设，坐标表不进入建模。DFT 输入中每条链必须化学完整，每个原子位置实际占位；互斥链不能同时放入，不能靠统一改占位或任意删去一半位点构造真实微态。[2，第 15–24 页]

**3. 按依赖关系推进计算**

| 阶段 | 具体工作 | 进入下一阶段的条件 |
| --- | --- | --- |
| A 输入与数值先导 | 独立化学生成并按三分支构造候选，核对链和层；用代表构型检查电子收敛、截断能、k 点、网格和优化耗时 | 输入来源合规、无重叠与断链；关键相对能、力和氢键几何达到可用精度 |
| B 固定胞联合精修 | 上述模型在对应的共同实验胞或其超胞中全原子优化；同时记录片层结构与层间位移 | 原始力、电子冷启动复核和数值加严检查通过；每个终态有明确约束状态 |
| C 滑移与自由终态 | 对 a、c 两项集体位移作少量受约束弛豫，选能谷释放约束；代表模型从轻微破坏对称性的起点重启 | 区分可保持终态、回滑终态和只在约束下保留的构型 |
| D 边界与应变复核 | 扩大一至两个代表堆垛超胞；检查边界与周期镜像影响；对代表终态释放适当晶胞自由度 | 域内及边界局部几何、能量差随尺寸和应变的变化得到控制或明确界定 |
| E 统计与衍射精修 | 用精修结构生成较长序列，拟合少量堆垛参数；按 X 射线和中子证据回选需要加密计算的局部环境 | 同时解释两类数据的主要趋势，报告模型族及参数可辨识范围 |

阶段 B 从首轮就包含堆垛构型。阶段 C–E 可以迭代：衍射指出最敏感的局部环境，补做该环境的精修，再更新散射模型。

**4. 氢键片层怎样精修**

主模型保留完整周期晶体环境，允许酰胺 H、N/O、碳骨架和链间位置共同调整。孤立片层会改变周围静电和色散环境，若用于机理分解，应另列为辅助对照。

O 分支从独立生成的有序候选作保对称基准，再选代表取消对称约束，并从小幅破坏对称性的起点优化；释放后的结果保留 O 来源身份。D1 与 D14 按各自微态约束处理，不把集合平均对称性施加于每个微态。ASE 的 FixSymmetry 会调整位置、力、应力和晶胞，因此受约束收敛不能单独证明自由结构也稳定；验收保留未投影的原始力并检查释放后的终态。[3] 原始力小也不等于完成声子稳定性证明，可疑畸变应补充定向扰动检查。

每个终态至少保存以下几何量：

- 不等价氢键的 N···O、H···O、N—H 距离及 N—H···O 角，同时保存供体—受体连接关系。
- C=O、C—N 键长、酰胺平面性、骨架扭转及片层起伏。
- 相邻片层的 a、c 向相对位移及法向间距。
- 域内与边界附近分别统计的数值和分布，不只报告全胞平均值。

解释重点是“堆垛改变引起了哪些局部几何变化”。较短的氢键或总能降低不能直接换算成单条氢键能；总能差还包括色散、静电、链构象应变及协同响应。

**5. 堆垛和小域边界怎样精修**

先根据完整结构恢复层数和层归属，再选能承载目标排列的超胞。沿 b 加倍的 304 原子胞是候选规模，不能预先认定足以隔离界面。周期末层与首层必须一起检查；代表构型需要扩大层数复核，确认界面附近和域中心的几何是否仍受周期镜像影响。

若片层由 a、c 张成，其法向平行于 b*，可用 a×c 确定一侧的法向。γ≈67° 时实空间 b 含层内分量，应使用法向投影求层间距，不能直接将 b 长当作片层距离。所有位移和结构匹配使用完整非正交晶胞度量。

滑移研究分成两类计算：

1. **受约束弛豫**：固定片层间的集体位移 u_a、u_c，放松内部原子和事先声明的其余自由度。先围绕文献注册位置及邻域取少量点，再对有意义的能谷加密。记录约束方向的回复力。
2. **解除约束的优化**：从不同能谷和边界构型出发，释放相对滑移及原子自由度。报告错位保持、回滑或局部重排的结果。受约束能量图不能直接称为最小能量路径或动力学势垒。

有序代表可在后续释放 a、b、c、γ。降对称超胞根据研究条件释放适当的应变自由度，不强行保留会抹除层错的空间群；若继续保持共同晶胞，应明确结果是在该应变条件下得到的。固定胞验收报告残余应力，不要求零应力；变胞验收才检查允许自由度上的目标应力。

短层序模型在面内无限周期，代表沿堆垛方向具有有限厚度的规则域及其平面边界。若讨论片层内部横向有限的小簇或另一取向的域边界，需要在相应方向扩胞并明确边界几何，不能把一维层序的结果称为所有三维有限小域结构。首轮优先精修与文献 a/2 片层错移直接对应的边界。[1，Fig.10]

界面代价先报告同尺寸、同应变条件下的超额能。只有当界面数量、等价性及尺寸收敛都明确时，才计算单位面积界面能；不能默认周期胞一定包含两个等价、互不影响的界面。

**6. 方法和精度如何沿用 PE 经验**

可以沿用 PE 的输入审计、同几何比较、固定胞到变胞、原始力验收和冷启动复核。PBE-D3(BJ)+ATM 可作为 PA6 基线候选；需要重新验证 C/H/N/O 设置与数值参数。对少数低能竞争结构做第二方法复核：先比较同几何能量，再优化代表，才能检查氢键几何的跨方法稳定性。

先导原始最大力可暂以约 0.002 eV/Å 为起点，并对少数终态加严，观察关键距离、角度和相对能是否变化。最终阈值按要分辨的物理差异确定。若排序小于数值或方法不确定性，保留近简并结论。论文 COMPASS 的 up–up/up–down 差折算约 1 meV/重复单元，只是精度需求的提示，不是已知 DFT 能差。[1，第 7–8 页]

相对能统一按 meV/C6H11NO 重复单元报告；边界超额能另行定义。PE 的 k 网格、bands、超胞重复数及 GFN2 标定误差不能直接移植。

首批候选数量少时，可直接开展 DFT 先导。GFN2 用于清理起始几何或扩展采样时，先检查它是否保持酰胺氢键连通、合理几何和堆垛多样性。只有需要用其能量筛选时，才建立 PA6 自己的同几何标定；若误差不适合排序，就缩小其职责。

**7. 怎样从精修结构得到统计无序模型**

用已精修的局部环境构造较长堆垛序列，初始仅设置少量参数：两种注册状态的比例、相邻层转移概率，必要时加入 c 向小位移的分布宽度。参数化须满足概率归一和统计一致性，不能把彼此依赖的比例及所有转移概率都当成独立变量。

先固定 A/B 标号与整体平移规范。若整体交换 A、B 等价于整个结构平移 a/2，则比例 p 与 1−p 描述等价结构，应合并报告，不能将两种标号当作两个独立解。

层的注册状态比例不直接等于 SI 互斥链位置的占位率；两者需经过明确的原子映射建立关系。将局部精修环境用于长序列时，还要检查共用片层坐标与周期成键的兼容性，不能直接拼接相互冲突的独立优化片段。

每个相干结构内计算完整结构因子，再对不同构型的强度作统计平均，即 I(Q)=〈|F_s(Q)|²〉，并结合纤维取向、仪器与样品条件比较。相关堆垛包含层间干涉，简单将两种无限有序晶体的强度各取一半，不能替代这种计算。Bragg 部分与漫散射对平均结构及相关性的约束不同。[4]

文献 50% 叠加作为复现基线，不预设为唯一最优比例；Fig.11 的约 0.01c 是模型示例尺度，不作为实测位移标准差。长序列主要用于散射计算，无需将文献的 50 片层模型直接全部交给 DFT。[1，第 8–12 页]

DFT 检查局部几何、相对能及可保持性，衍射约束这些局部环境的分布。暂不把零温小胞能量直接换算成实验 Boltzmann 权重，也不任意将能量和 R 值相加为单一评分。若要预测有限温度分布，需要另建包含相关相互作用、熵及必要热效应的统计模型。

**8. 实验对照与第一阶段交付**

WAXD 与 WAND 共同约束局部结构族，各自保留尺度和必要实验参数。N6-h10 与 N6-d10 制样不同，应检验它们能否共享同一堆垛分布。中子模型中亚甲基为 CD2、酰胺 NH 仍含 H，另建同位素映射。[2，第 2 页]

现有 SI 可支持合并 hkl 峰组强度及逐层归一化的比较；有序模型预测过强而实验不显著的峰，应结合正文图作检查。正文与 SI 的 P1 残差存在出入，必须统一峰组、观测值和归一化口径。论文 R 不是 Rwp。[1，第 9 页；2，第 25–28 页]

现有数据适合筛选模型族及少量参数，不能据此唯一确定随机层序、精确域尺寸或没有测量误差支撑的严格置信区间。进一步约束相关长度和连续漫散射，需要原始二维或三维散射数据及实验条件。[4]

第一阶段应交付：

1. 不含原文坐标的输入与独立化学模板；O、D1、D14 三套候选库及各自去重结果。
2. 有序、错位及边界环境中的氢键精修表和结构文件。
3. 受约束滑移结果与释放后终态，明确哪些环境独立保留。
4. 关键能差、局部几何的数值验证，代表边界的尺寸及应变检查。
5. 同时接受 WAXD/WAND 检验的结构族，以及统计参数可接受范围。

首轮执行顺序为：**限定文献输入 → 独立化学构造 → O、D1、D14 分别生成和检查 → 各分支普通 PA6 精修及方法复核 → 分支内分组 → h10 X 射线与 d10 中子散射对照 → 跨分支比较。** 同位素振动按需后置；原子数和单步计时出来后再安排批量计算。项目启动安排见 [PA6 项目设计](E:/PA6_DFT/README.md)。
