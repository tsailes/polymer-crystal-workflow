# 尼龙6计算的PE路线迁移与结构识别规范

2026 年 10 月 29 日，规范 v0.3。主体只计算普通 PA6，氘代首轮仅作中子散射标签映射；同位素振动后置。候选不使用原文原子坐标；O 有序、D1 统计无序 P1、D14 统计无序 P112₁/n 三条分支独立生成、计算和分组。本文为计算前的方法审查与先导验收设计；下列 PA6 门槛尚未通过实际计算验证。

**结论：沿用 PE 的可追溯计算与数值验收体系，重新建立 PA6 的候选空间、结构身份和保留规则。** 本次要精修的氢键、片层错位及边界差异，必须在预优化、归组和终态验收中始终保留。

PE 是思路可行性的最小实例。下列实现差异用于说明扩展模块的工作范围，不用于否定该思路；当前三分支生成及同位素规则见[三分支候选生成与氘代处理](E:/PE_DFT/reports/PA6计算实验设计_20261029/三分支候选生成与氘代处理.md)。

**1. 哪些 PE 做法可以迁移**

| PE 做法 | PA6 处置 | 依据与实际改变 |
| --- | --- | --- |
| 输入来源、轴序、单位、哈希和失败记录 | 沿用 | 增加原子—单体—链—片层—界面的对应表 |
| 接触过滤和周期成键检查 | 重写材料规则 | PE 生成器只含 C/H 半径；不能把统一 0.85 倍范德华半径门槛直接施加于 N—H···O 接触 |
| GFN2 预优化后只选组代表进入 DFT | 首批暂停作为压缩候选的关口 | 三分支各自保留直接 DFT 通道；另设少数 GFN2→DFT 支路，检查是否提前抹去结构差异 |
| 同几何标定、独立冷启动、单因素加严 | 沿用 | PA6 必须新增 N/O、氢键和层错环境；PE 初态域的 σ 不适用 |
| 3σ 能量剪枝 | 首批不启用 | PE 原记录的自动能量淘汰数为 0，未验证这种剪枝不会漏掉 PA6 目标结构 |
| PBE-D3(BJ)+ATM | 作为主线候选 | 数值稳定不等于对 PA6 的物理准确性已验证；需要代表性氢键几何和堆垛的第二方法复核 |
| optB88-vdW、r²SCAN-D4 | 选择性复核 | PE 的正式代表比较为冻结几何单点，不能改称跨方法几何验证；PA6 要优化关键代表才能比较几何 |
| 原始力、固定胞与变胞分开验收 | 沿用原则 | 受约束滑移点单列约束回复力；有序单斜胞与降对称超胞分别定义应变自由度 |
| PE 正交胞匹配及变胞实现 | 不能直接调用 | 匹配程序明确拒绝非正交胞；原变胞脚本锁定 PE 对称性与正交应变设置 |
| 完整链接归组 | 沿用分组原则，替换比较内容 | 每对同时通过周期原子映射、化学拓扑、氢键与层序/界面检查，不能只靠能量和全胞 RMS |
| 仅一个代表变胞 | 改为各非等价结构族保留代表 | PE 最终一组是计算结果，不能成为 PA6 的预设目标 |
| 峰位验收 | 扩展 | PA6 还需 WAXD/WAND 强度、额外强峰及相关散射约束 |

实际代码的材料绑定已核实：PE 匹配器要求同一正交胞；生成器使用 Pnam、对角胞和 C/H 半径；优化设置默认 16 bands，部分输出按 CH2 归一。仅替换输入结构会导致拒绝运行或错误统计。新材料应使用独立配置和经过检验的 PA6 识别器，保留 PE 历史记录。[3–6]

PE 的原始 DFT 发布锁明确只验证了两套 C4H8 冻结几何及 PBE-D3(BJ) 的 PE 胞比较，并未自动覆盖新元素或大幅改变的晶胞。[4]

**2. 点群和空间群现在能确定到什么程度**

| 对象 | 文献表示 | 对应晶体点群 | 对本次计算的含义 |
| --- | --- | --- | --- |
| 有序 regular zigzag 参考 | P112₁/n，No.14，c 轴设置 | 2/m，即 C₂h | 可作为明确的有序构造先验和复现基准 |
| 统计无序 P1 模型 | P1，No.1 | 1，即 C₁ | 一种平均结构表示，不证明所有实际局部域均为 P1 |
| 统计无序 P2₁/n 模型 | No.14，本文轴序 | 2/m | 同样能解释部分实验，文献没有唯一排除它 |
| 本次满占位堆垛/边界构型 | 建模后及优化后识别 | 待判定 | 不能仅凭平均模型名称预设全部微观构型的对称性 |

SI 第 22 页的四个操作是：

```text
x, y, z
-x+1/2, -y+1/2, z+1/2
-x, -y, -z
x+1/2, y+1/2, -z+1/2
```

其旋转部分分别为恒等、绕 c 的二重旋转、反演和垂直 c 的镜面，对应 2/m。操作表只定义允许的对称假设与设置；O 分支从独立化学几何生成候选，另核验原点、计量和周期链连接，不读取 Table 1 坐标。[1，第 5、7 页；2，第 22 页]

同一点群、同一空间群内可以存在不同坐标、链相位和堆垛。反过来，边界使整体降为 P1，也不自动意味着出现了另一种聚合物晶型。无对称约束优化是计算设置；最终是否具有更高对称性，应从终态重新识别。

对称性识别保存空间群编号、Hall 设置、点群、变换矩阵、原点位移、操作列表、等价原子及操作残差。spglib 返回失败时应标为识别失败，不能用 P1 填补。[7]

100 K 正文胞为 9.43、7.62、17.46 Å，γ=67°；SI 的 c=17.4560 Å 另记来源，不默默混用精度。N6-d10 的亚甲基氘代、酰胺 NH 保留 H；电子结构的元素标签与中子散射的同位素标签分开保存。

Table 1、SI 原子坐标及其派生链模板、键长、角度和扭转不用于候选或优化起点；不能以复制后扰动替代独立生成。由独立内部坐标构造的几何应记录模板来源、自由度及随机种子。用指定操作生成后出现精确对称只验证构造规则，不是对真实晶体对称性的独立证明。

**4. 一个结构需要保存什么身份**

结构身份至少包含四层信息：

所有记录先带 O、D1 或 D14 分支身份，分支内分别分组；另保存生成器版本、集合编号、微态编号和 h10/d10 同位素身份。平均集合的点群与每个微态的点群分别记录。不同分支即使得到相同终态，也只建立跨分支关联，不合并来源、组号或误差统计。

1. **化学与链**：元素计量、周期共价图、单体、完整链及链方向。匹配时保持共价连接和化学角色，不允许任意重排同元素原子来掩盖连接改变。
2. **局部片层**：氢键供受体图、N···O/H···O 距离、N—H···O 角、酰胺平面性、骨架扭转及层面起伏。先比较连续几何，再检查拓扑边界是否稳健。
3. **完整堆垛**：逐层相对位移 Δa、Δc、法向间距、循环层序及每个边界的位置。A/B 整体换名、整体原点平移等须消除规范冗余。
4. **对称与计算状态**：空间群、点群、容差、操作残差、晶胞条件、约束状态、数值设置和优化是否验收。

**同一结构的比较使用一个全局一致映射。** 可以换原点、合法换胞、全局刚性转动及周期包裹，但不能逐片层分别平移到最佳重合后，再据此宣布整个晶体相同。局部对齐只用于回答“片层形状是否相似”，不能用于抹掉堆垛差异。

非正交周期距离应求所有相关晶格平移中的最短距离，不能把分数坐标差逐项四舍五入就当作通用最小镜像算法。晶胞不同时，先统一基矢和对应关系，再分别报告应变与内部原子差异；不通过任意缩放消除真实结构差异。

应分开报告四种结论：严格表示等价；在指定容差下近似相同；不同起点优化至同一终态；几何不同但能量近简并。实验不能区分两种结构，也不等于两者原子坐标相同。

**5. 首轮门槛与使用方式**

以下是可用于先导试验的工作值，不是从论文得到的精修精度，也不是已通过 PA6 验证的生产标准。

| 检验 | 先导设置或原则 | 不通过时怎样处理 |
| --- | --- | --- |
| 化学硬检查 | 计量、完整周期链及互斥占位必须正确；没有同时占据的重叠原子 | 修复输入，不能靠放宽数值容差通过 |
| 接触与氢键候选 | 可暂用 N···O≤3.5 Å、H···O≤2.6 Å、角≥120°辅助识别候选边；同时保存连续几何 | 此范围不作“强氢键”定义或自动删结构门槛；临界边以距离±0.1 Å、角±10°检查敏感性 |
| 对称性扫描 | symprec 取 10⁻⁵、10⁻⁴、10⁻³、0.003、0.01、0.03、0.05 Å；角容差先使用自动方式 | 保留全扫描与操作最大残差；只在大容差恢复高对称时标近似，不挑选合意的群号 |
| 固定胞原子优化 | 先导原始 Fmax≤0.002 eV/Å；关键终态加严并检查几何和能差变化 | 冷启动或加严后漂移则继续优化；不把 SCF 收敛等同原子收敛 |
| 两个终态近似归组 | 拓扑与层序/界面身份一致；同一映射下全原子 RMS≤0.02 Å、最大偏差≤0.05 Å作为起始检查值 | 单独检查 NH 和边界；不同层序不因平均偏差小而合并 |
| 局部几何复核 | 对应氢键距离差暂取≤0.03 Å、角差≤3°；逐界面位移差暂取≤0.03 Å | 超限或临界单列；用加严优化与门槛敏感性决定最终标准 |
| 变胞结果对照 | 相同设置下，长度差≤0.2%、角差≤0.2°仅作同方法终态比较的初筛 | 后续仍须全部原子、拓扑和界面检查；跨泛函或对实验的差异不能简单按此判失败 |
| 相对能精度 | 数值变化应明显小于要判别的能差；若目标差约1 meV/重复单元，可先争取稳定到0.2–0.3 meV/重复单元 | 达不到就报告不可分辨，不人为拉开排序；该尺度需实际先导确认 |

几何归组门槛缩小到一半、放大到两倍后，检查核心结论是否变化。阈值决定归属的边界样本保留为待判定，不自动删除。氢键拓扑变化若只由候选边阈值轻微移动造成，也应标为临界，不立即宣布形成新结构。

能量不是结构等价的证明。对同尺寸同应变的体相比较可用每重复单元能差；边界另列超额能及局部几何。固定数量边界原子的位移在更大超胞中会被全胞 RMS 稀释，界面超额能除以重复单元数也会变小，故这两项均不能代替逐界面识别。

**6. 如何证明识别器确实能区分目标结构**

| 验证组 | 输入变换 | 预期结果 |
| --- | --- | --- |
| 表示等价正对照 | 原子编号重排、整胞平移、周期包裹、合法换胞、同一结构重复成超胞 | 认回相同结构，给出可逆的原子及基矢映射 |
| 局部差异负对照 | 构造并核实非等价的单片层 a/2 错移、某个界面 c 向错位、层错或氢键连接改变 | 指出差异发生在哪个层、界面或供受体，不能仅输出一个距离 |
| 数值扰动对照 | 对同一结构加入已知量级的小扰动 | 精确等价与近似匹配分开；若声称同一优化终态，还要实际重新优化确认 |
| 超胞尺寸对照 | 保持相同局部缺陷而扩大远离缺陷的区域 | 即使全胞平均偏差变小，仍能检出该缺陷 |
| 对称识别对照 | 指定操作构造的有序胞与其明确破坏对称性的版本 | 前者操作映射一致；后者不靠大容差强行恢复预设对称性 |
| 独立几何复核 | 用显式邻胞枚举复核非正交最小距离；抽取最差原子和边界作图 | 验证距离、映射和局部标签，避免同一算法自证 |
| 终态计算复核 | 对拟合并终态用同一 DFT 设置冷启动并加严 | 相同结构应保持几何和能量一致；不稳定或仍漂移的样本不进入已验收组 |
| 实验外部检验 | 各结构分别计算 WAXD/WAND 强度、额外强峰及必要相关散射 | 检验结构族是否解释实验；有限数据不区分时保留多个解 |

这些是拟执行的验证项目；当前尚未生成 PA6 模型或运行识别器，不能写作测试已通过。

**7. 最小方法衔接试验**

第一轮从 O、D1、D14 各自独立生成的候选库选择代表，分别保留直接 DFT 通道；数量按分支自由度及结构覆盖决定。选择有序结构和无序分支的边界微态，额外走 GFN2→DFT 支路：比较是否改变氢键连通、层序、边界身份及最终几何。若不一致，保留直接 DFT 结果并缩小 GFN2 的筛选职责，不能用其合并结果提前排除候选，更不能跨分支汇总为统一剪枝统计。

数值先导覆盖参考胞与一个不同堆垛，重点看相对能和 N/O/NH 的力。补充代表性的酰胺位移、片层滑移及单斜剪切导数检查，区分力与应力实现正确性和数值噪声。晶胞应变自由度按实际基矢定义；PE 的 Cartesian strain mask 不能简单解释为 PA6 的 a/b/c/γ 开关。

主线可先用 PBE-D3(BJ)+ATM。三个有序代表先用 r²SCAN-D4 等第二方法比较同几何能量和力，随后用两方法分别优化有序参考及最有竞争性的堆垛，检查氢键几何。r²SCAN-D4 的原始研究提供了分子晶体与非共价相互作用基准，可支持把它列作复核候选，但不能替代 PA6 验证，也不能把它自动视为真值。[8] 若排序随方法改变，结论保留方法敏感性；optB88-vdW 可作为出现实质分歧后的第三个对照。

现有 PE 工具包含三方法的能量、力和应力单点路径，但原变胞程序限制 PBE-D3 的参数定义，不能只修改方法名称就运行第二方法变胞。PA6 新分支需先确认能量、力与应力来自同一个明确的方法组合。

八重复单元 PA6 胞按常用价电子计数有 368 个电子，中性非自旋极化时有 184 个占据态；具体 bands 和 N/O PAW 需与实际实现一致。PE 的 16 bands、12 原子数组、每 4 个 CH2 归一和固定正交设置都必须改造。先完成少量单步计时，再决定超胞与并行规模。
