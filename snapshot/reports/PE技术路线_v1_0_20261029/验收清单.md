## 输入与候选

- [ ] 明确组成、重复单元、周期、空间群及轴序、晶胞、构象与允许自由度；区分实验先验、生成输入和验证数据。
- [ ] 核对周期成键图、化学连通性和目标对称性；保存独立生成规则与来源。
- [ ] 记录枚举范围、步长、全部组合、接触门槛、排除原因及等价映射；不将预筛域误写为完整优化域。
- [ ] 固定胞密度仅作输入检查；不将其作为候选堆积的独立筛选信号。

## 低成本预优化与标定

- [ ] 记录低成本模型实现、软件版本、周期采样、电子占据、优化器和原始/投影力；核查选定能量导数及周期一致性。
- [ ] 粗精预优化、终态冷电子复核、代表密采样及自身 Fmax 均符合该实例目标；新几何重新验收。
- [ ] 对可疑高对称驻点作声明方向的正负扰动诊断；有下降方向则单列，不将小力等同于稳定。
- [ ] 同几何配对具有相同坐标、晶胞和哈希；相对能在各方法内使用相同参考身份，单位一致。
- [ ] 明确标定样本域、n、参考、b、σ 的 ddof 与 3σ 解释；初态、终态和对照不混作样本。
- [ ] 若无低能窗口和冻结筛选规则，保留代表；不把几何合并计作 σ 筛选或节约计算。

## DFT 与终态

- [ ] 方法、色散、PAW/赝势、软件环境、SCF、Ecut、k 点和实空间网格有固定记录；完成能量、力、应力相关数值验证。
- [ ] 正式计算使用的是该阶段实际生产设置；历史候选精度、导数探针与生产参数分开。
- [ ] 固定胞优化核查原始 Fmax、SCF、胞不变、对称性和独立冷启动；应力只记录。
- [ ] 终态合并有同一原子映射下的 RMS/最大位移及同方法能差；DFT 组内全部两两通过，不用连锁相近替代。
- [ ] 变胞从指定已验收结构出发；自由度、胞角和外压明确；原始力与六应力分量联合通过。
- [ ] 冷启动不继承电子态；末态 k/grid/Ecut 加严保留共同几何和单因素比较基线。
- [ ] 未通过则保存失败原因，修复后新建 attempt；不覆盖失败或静默放宽科学阈值。

## 实验对照与发布

- [ ] 固定胞、变胞及校准参考有独立 structure_id、stage、method、parent_id、参数和哈希。
- [ ] 坐标比较记录轴序、原点、周期映射、元素匹配及参考不确定性；不混淆优化位移与对实验偏差。
- [ ] 胞参数比较标注实验温度；不将静态电子能结果当作有限温度核自由能结果。
- [ ] XRD 注明波长、hkl 索引和 d 值数量；只有峰位数据时不报告整谱强度拟合指标。
- [ ] 保留未改善的指标；结论不超出候选域、对称约束、局部优化及已完成检验。
- [ ] 保存结构、能量/力/应力表、轨迹和日志索引、方法锁、合并映射、终态验收、失败/取消项和来源哈希。
- [ ] 变更记录注明相对前版的参数/样本域差异与受影响结论；未运行和取消分支不计为已完成。

## PE v1.0 验收参照

PE 主线已经完成；严格固定胞四代表、六对合并和新 g4 变胞/冷启动/数值复核均有通过记录。当前没有声子、零点能、温度自由能、最终 g4 跨泛函几何优化或连续实测强度谱拟合结果。这些不构成本版路线交付的缺失项；若研究主张扩展到相关问题，应建立单独任务与版本。

PBE0、正式效率对照及 80/85/90°补充角分支保持原有取消或未运行状态。参见[技术路线](技术路线.md)和 [route_lock.json](route_lock.json)。
