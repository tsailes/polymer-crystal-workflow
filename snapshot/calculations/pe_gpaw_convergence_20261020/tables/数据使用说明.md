# PE 计算数据使用说明

本页按2026-10-20实际 CSV 列名编写。表格会随计算更新；有数据不等于该阶段已经验收。

[全部运行能量表](E:/PE_DFT/calculations/pe_gpaw_convergence_20261020/tables/energies_all_runs.csv)汇总已登记单点，包含成功、失败、中断和尚无结果的记录。先筛选 `status=passed_single_point`，再按 `stage`、`method`、`geometry_sha256` 分组。后者是源结构文件指纹；`actual_geometry_sha256` 对应实际晶胞和坐标等内容，同源文件施加位移或应变后可以不同。还须核对数值设置与 `dispersion_parameters`。`displacement`、`strain` 及诊断 probe 用于验证导数，不能混入候选排序。失败行和空值应保留，空值不是零；`no_result` 也不单独证明失败。

主要能量列的含义如下：

| 列名 | 含义 |
|---|---|
| `energy_free_eV_cell` | 与力一致的总电子自由能，单位 eV/晶胞；本轮比较优先使用。 |
| `energy_extrapolated_eV_cell` | 占据展宽外推总能量；与前列分别保留，不能任意混用。 |
| `energy_eV_atom`、`energy_eV_CH2` | 由总自由能分别除以12个原子、4个CH₂得到。 |
| `energy_Ry_cell` | 同一总自由能换算为 Ry/晶胞。 |
| `dft_energy_free_eV`、`dispersion_energy_eV` | DFT自由能与外加色散能，均为 eV/晶胞；两者相加得到总自由能。 |

PBE-D3(BJ)和r²SCAN-D4的色散列分别含D3、D4修正；optB88-vdW的非局域相关已计入DFT，外加色散为零不表示没有范德华作用。这些能量不含声子、零点振动或有限温度晶体自由能。不同泛函的绝对能量不能直接比较准确性；结构间能差须在同一方法、PAW和相容精度下比较。

[固定几何收敛表](E:/PE_DFT/calculations/pe_gpaw_convergence_20261020/tables/convergence_summary.csv)用于判断数值精度，查看 `group_status`、`terminal_confirmed`、`all_pass_terminal` 与 `recommended_run`；某一行通过不等于整个任务完成。[相对结构能表](E:/PE_DFT/calculations/pe_gpaw_convergence_20261020/tables/relative_structure_energies.csv)中的 `relative_energy_meV_atom` 为 `(E_GFN2−E_Tashiro)/12×1000`，负值仅表示这两套冻结坐标下GFN2结构较低；结合 `family_status`、`candidate_accepted` 判断收敛。

[优化能量表](E:/PE_DFT/calculations/pe_gpaw_convergence_20261020/tables/relaxation_energies.csv)按 `evaluation_id`、`optimizer_step` 展示结构变化。`total_energy_free_eV` 是每胞总自由能，`raw_fmax_eV_A`、`raw_stress_max_kbar` 是未投影的最大力和应力。`row_status=valid` 仅说明该行可读；优化完成须核对 `run_status` 和最终结果。运行期间部分状态列可能为空。

[电子迭代表](E:/PE_DFT/calculations/pe_gpaw_convergence_20261020/tables/scf_iterations_all.csv)中的 `e_total_free_eV` 是GPAW电子自洽过程的DFT能量，未加外部D3/D4；不能把中间迭代当收敛终能。原始输入、结果、`gpaw.txt`、`scf_iterations.jsonl`、标准输出和错误日志位于[单点目录](E:/PE_DFT/calculations/pe_gpaw_convergence_20261020/runs)各 `run_id` 子目录；结构优化记录位于[优化目录](E:/PE_DFT/calculations/pe_gpaw_convergence_20261020/relaxations)。表内 `result_json` 或 `source` 可追溯原文件；其中 `/mnt/e/` 对应Windows的 `E:/`。
