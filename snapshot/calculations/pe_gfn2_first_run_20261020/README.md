**后续阶段已完成（2026-10-20）：周期采样检查与固定晶胞局部优化。**
采用2×3×8 Γ点重复超胞，26步后最大受力0.009876 eV/Å；3×4×10终态复核仍达标。
见[本轮结果与前三个研究级别的说明](convergence_relaxation/runs/20261020T063341_922507Z/result_report_zh.md)及[复现入口](convergence_relaxation/run_convergence_relaxation.ps1)。
本轮只有一个初猜进入优化，批量候选生成、DFT参考方法校准和3σ误差标定尚未开展。下文保留首次单点计算的原始说明。

本次任务：配置独立计算环境，从化学几何生成 PE 周期初猜，获得一次固定几何下的 GFN2-xTB 能量与原子受力，并检查数值接口。

## 第一步：安装能计算周期体系的后端

本次通过验证的主计算后端为独立安装的 tblite 0.7.0，通过 ASE 接口运行 GFN2-xTB。已经获得周期能量、原子力和应力，并通过选定分量的数值一致性检查。

- 独立 Python 环境：`/opt/pe_dft/envs/gfn2-pe-20261020`。
- 安装日志、版本、构建选项和官方参考算例验证：`environment/`。
- 另行安装的 DFTB+ 25.1 / tblite 0.3.0 集成版通过了自带参考算例，但在本 PE 模型的能量—导数检查中未通过门槛，已经标记 `quarantined_do_not_optimize`，不作为默认入口。它的安装与失败记录保留在 `environment/dftbplus/`、`runs_dftbplus/`。
- 旧集成版本的差分偏差尚未定位；新接口通过本次检查，不等于已经证明对实验更准确。

## 第二步：建立周期链

`build_pe.py` 用解析几何生成两条全反式无限链，晶胞内 C4H8，共 12 个原子、4 个 CH2 单元。所有 H 均显式存在。跨 c 边界的 C-C 键使一个有限晶胞表示无限链，没有分子端基。

晶胞 a=7.432、b=4.929、c=2.545 Å，三个角为 90°。这些尺寸采用本项目 Tashiro 1997 文献记录中的实验晶胞先验；本次没有预测晶胞尺寸，也没有使用文献精修原子坐标。具体来源与哈希见 `model/provenance.json`。

C-C 初始键长为 1.54 Å，C-H 为 1.09 Å。由固定链周期和 C-C 键长共同决定锯齿链角度，H 通过四面体方向关系构建。两条链的初始转角为 17°、43°，相对轴向相位为 0.17 个晶胞。它们是任意初猜，不是精修链取向。原始 17°/103° 初猜的近接触较短，几何筛选后改为 43°；原模型和记录保存在 `model/geometry_trial_17_103/`。

`model/geometry_validation.json` 检查每个 C 为 2C+2H 邻接、每个 H 为 1C 邻接，并保留跨周期成键向量。正交晶胞度量不等于已恢复正交 PE 的实际空间群或链堆积。

## 第三步：固定原子位置，计算能量和力

单点计算先固定原子与晶胞，让电子分布达到自洽，然后输出能量、原子受力与应力。总电荷为 0，采用闭壳层。电子占据温度 300 K 是数值占据展宽，不表示进行了 300 K 分子动力学，也不是对实验温度的认定。

能量以 eV/晶胞记录，同时按 CH2 归一化。原子力以 eV/Å 记录。原子力满足 F=-dE/dR；初始结构存在非零受力是正常的，说明后续几何优化还有移动空间。绝对总能量的负值本身不能证明结构稳定，后续要比较相同方法、组成和收敛设置下的相对能量。

## 第四步：核对数值接口

预先规定的检查包括：

1. 从基点中选绝对值最大的一个力分量，分别移动该原子 ±0.0001 Å，中心差分力与解析力误差须小于 0.001 eV/Å。
2. 整体平移并进行周期包裹，能量变化须小于 0.000001 eV，最大力分量变化须小于 0.00001 eV/Å。
3. 对 yy 方向施加 ±0.0001 相对应变，用能量差核对一个应力分量，误差须小于 0.0001 eV/Å³。

这些检查验证特定分量的单位、符号与实现一致性，不替代所有力分量的验证或与 DFT/实验的精度标定。

## 复现与本次范围

Windows 入口是 `run_first_calculation.ps1`。它调用独立环境中的 `run_gfn2.py`，每次建立新的 `runs/` 运行目录，保留原生输入、输出及结构。正常完成需全部预设技术检查通过；失败时返回非零退出码。

本次主基点使用 Gamma 点。额外检查了沿 c 重复 1、2、4、6 次的超胞，发现最小晶胞 Gamma 点明显不足。该扫描只是沿链采样敏感性诊断；正式能量排序前还需要完成更密采样及横向收敛。本任务不包含结构优化、全局搜索、三泛函标定，或者证明已经得到正确 PE 晶型。
