# PE 四个代表结构的 DFT 固定晶胞精修

本批于 2026-10-22 启动。目标是判断第三阶段 GFN2 优化后得到的四个代表，在同一 DFT 模型下继续优化后还剩多少个可区分结构。运行中状态见 `control/workflow_state.json`；最终结论见 `results_summary.md` 和 `tables/refinement_summary.json`。尚未通过全部终态验收时，汇总明确标为 partial。

## 固定的计算条件

- 方法：GPAW 平面波 PBE-D3(BJ)，沿用已核验的 C/H PBE PAW 数据集。
- 截断能：1800 eV；Gamma 居中 k 点：4×8×12；实空间网格：112×72×44；16 bands；XC stencil=4。
- 晶胞：a=7.432 Å，b=4.929 Å，c=2.545 Å，三角均 90°；12 原子 C4H8，每胞 4 个 CH2；固定晶胞并保持 Pnam 对称操作。
- 原子优化：LBFGS，最大步长 0.05 Å，最多 200 步；原始最大原子受力≤0.002 eV/Å。
- SCF 阈值：能量 1e-9 eV/electron，密度 1e-9 electron/electron，本征态误差 1e-11 eV²/electron；电子展宽为零。
- 每项 4 个 MPI 进程、最多两项同时运行。达到优化条件后，用全新电子密度和波函数初猜进行独立终态复核。
- 应力完整保存；固定晶胞计算不以应力为零作为收敛要求。没有加入零点能或有限温度振动自由能。

这些精度值沿用第三阶段 H 级设置及既有数值验证；其出处和文件哈希见 `protocol.json`、`reference/`、`audit/preparation.json`。它与第二阶段变胞验证的用途不同：本批移动原子，a、b、c 不变化。

## 如何判断合并

四点均通过优化、SCF、固定胞、Pnam 及独立终态验收后，比较全部六对终态。允许周期边界、等价原点、正交胞轴反射及同元素原子映射。需同时满足：原子位移 RMS≤0.02 Å、最大位移≤0.05 Å、能差≤1 meV/CH2。

分组要求同组内每一对都通过，避免 A 接近 B、B 接近 C 就直接认定 A 与 C 相同。若存在多种同样成立的分组，将保留歧义。合并是保留原编号与全部数据的结果归类，不删除原计算。

结论限于这四个起点在给定晶胞、Pnam 和 PBE-D3(BJ) 下的优化结果。力收敛不等同于已经完成振动稳定性验证，也不能据此宣称找到全局基态或证明多个独立晶型。本批暂不加入变胞或另外两种泛函的结构优化；原有三泛函单点结果保留在第三阶段目录。

## 数据与监控

- `structures/`：四个冻结起始结构；`sample_manifest.json`：来源与哈希。
- `runs/group_00*/attempt_01/`：每点独立输入、程序快照、标准输出/错误、全部电子迭代和结构优化日志、逐次能量/受力/应力/坐标、轨迹、最终 POSCAR/CIF/GPW 与终态复核。
- `tables/`：逐步能量、电子迭代能量、最终能量、六对几何/能量比较及原子映射；计算未结束时可能仅有部分结果。
- `control/`：队列状态、后台启动记录、防休眠状态和诊断。失败会保留证据并停止新提交，已经在算的项目可正常结束，不自动放宽数值门槛。

Windows 防休眠只设置本批运行期间的临时系统请求，允许显示器关闭，不改变全局电源方案；实际计算进程结束后自动释放。后续监控每 15 分钟检查一次，仅在实质进展、完成或异常时汇报。
